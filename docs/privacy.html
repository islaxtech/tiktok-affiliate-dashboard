Privacy Policy

Effective date: September 5, 2026

Summary

Affiliate Dashboard (the “app”) runs on the user's own machine and stores the user's own TikTok Shop affiliate data in a database file on that machine. It collects no data from third parties, operates no server, and shares nothing with anyone.

What the app collects

The app collects no personal data from third parties. It does not gather, request, or receive personal information about anyone other than the user who authorized their own TikTok Shop affiliate account.

The data the app reads through the TikTok Shop API is the authorizing user's own affiliate data: their sample applications and fulfillment status, their target collaborations, orders attributed to their content, their creator profile, and their showcase products. This data is stored locally, on the user's machine, and nowhere else.

OAuth tokens

To read the user's own affiliate data, the app uses TikTok OAuth access and refresh tokens for that single account. These tokens are stored locally on the user's own machine only. They are transmitted only to TikTok's API, to authenticate the user's own requests. They are never sent anywhere else and are never shared.

No tracking

The app uses no analytics, no cookies, no advertising, and no third-party data sharing of any kind. There is no telemetry and no usage reporting.

Read-only access

The app is read-only. It requests read scopes only, sends no content to TikTok, and modifies nothing on the platform. It cannot post, message, accept a collaboration, apply for a sample, or change a showcase.

Data deletion

The user can remove everything at any time:

  • Revoke the app's access in their TikTok account settings, which invalidates the tokens.
  • Delete the local database file on their machine, which removes the stored data.

There is no server-side data to delete, because the app stores nothing remotely. Once the local database file is deleted, no copy of the data remains.

Children

The app is not directed at children and is intended for use by TikTok Shop affiliate creators operating their own accounts.

Changes to this policy

If this policy changes, the revised version will be published on this page with an updated effective date.
