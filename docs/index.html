The problem

Sample and collab status is scattered

An affiliate creator's work is spread across several different places in the TikTok Shop app: the sample you applied for, the shipment that may or may not have arrived, the collaboration invitation sitting in a message thread, and the orders that were actually attributed to your videos.

It is easy to lose track of what shipped, what arrived, and what still needs a reply before it expires. Nothing is broken — the information is simply not in one list you can read top to bottom.

Affiliate Dashboard reads that information through the official TikTok Shop API and lays it out in a single local view.

The four views

One list for each part of the job

Every view is assembled from data the creator's own account already has access to.

📦

Samples

Every sample application in one list, with its current fulfillment status — applied, approved, shipped, delivered — so nothing sits in limbo unnoticed.

🤝

Collab invites

Target collaboration invitations gathered together, so an invitation that needs a reply before it expires is visible rather than buried.

🛍️

Showcase

The products currently on the creator's showcase, listed alongside the samples and collaborations they came from.

📈

Earnings

Orders attributed to the creator's content, so commission can be traced back to the sample or collaboration that produced it.

Read-only by design

Affiliate Dashboard performs no writes, sends no messages, and takes no action on the platform. It requests read scopes only, and the HTTP client refuses any request that is not on an explicit allowlist of read endpoints.

Accepting a collaboration, replying to a message, or applying for a sample is still done by the creator, in the TikTok Shop app. This tool only shows what is there.

Project status

Where this is today

Affiliate Dashboard is currently in development. It runs locally on the developer's own machine and is being validated against the developer's own creator account first, so that the read-only behaviour and the data mapping can be checked against a real account before anyone else connects one.

The intent is for this to become a tool other affiliate creators can use. It is an independent project, and is not affiliated with, endorsed by, or sponsored by TikTok.
